================================================================================
     SR-VORTEX  -  LEIA ANTES DE INICIAR O BOT
     Funciona em Windows E macOS
================================================================================

Leia TUDO antes de fazer qualquer coisa.
Siga na ordem. Cada passo depende do anterior.


================================================================================
  PASSO 1  -  EXTRAIR O ZIP
================================================================================

  WINDOWS:
    - Clique com o botao direito no arquivo SR-VORTEX-XXXXX.zip
    - Escolha "Extrair tudo..." (ou use o WinRAR / 7-Zip)
    - Extraia para uma pasta facil, tipo:
        D:\SR-VORTEX
      ou
        C:\Users\SeuNome\Desktop\SR-VORTEX

  MAC:
    - Clique duplo no .zip (extrai automaticamente no Finder)
    - Mova a pasta SR-VORTEX para onde quiser, tipo:
        ~/Desktop/SR-VORTEX
      ou
        ~/Documents/SR-VORTEX

  >>> NAO extraia dentro de pastas do sistema <<<
  >>> NAO deixe dentro de pastas com acentos no caminho <<<


================================================================================
  PASSO 2  -  INSTALAR DEPENDENCIAS
================================================================================

  O instalador automatico cuida de TUDO: Python, Node, Playwright,
  Tesseract, npm install. Pode levar de 3 a 10 minutos.

  -----------------------------------------------------------------------
  WINDOWS:
  -----------------------------------------------------------------------

  Duplo clique em: INSTALAR_DEPENDENCIAS.bat

  Na primeira vez, rode como administrador:
    Botao direito > "Executar como administrador"

  Se o CMD fechar sozinho:
    Abra o CMD (Win+R > cmd > Enter)
    cd /d D:\SR-VORTEX
    INSTALAR_DEPENDENCIAS.bat

  -----------------------------------------------------------------------
  MAC:
  -----------------------------------------------------------------------

  Duplo clique em: INSTALAR_DEPENDENCIAS.command

  Se aparecer "nao pode ser aberto porque e de um desenvolvedor nao identificado":
    Botao direito > Abrir > Abrir

  Se aparecer "permissao negada":
    Abra o Terminal, va ate a pasta do projeto e rode:
      chmod +x *.command
      bash INSTALAR_DEPENDENCIAS.command

  Pre-requisito Mac: Homebrew (https://brew.sh)
  O instalador tenta instalar o Homebrew se nao tiver.

  -----------------------------------------------------------------------
  INSTALACAO MANUAL (os 2 sistemas):
  -----------------------------------------------------------------------

  Se preferir instalar manualmente:

  WINDOWS (PowerShell):
    cd D:\SR-VORTEX
    python -m venv venv
    .\venv\Scripts\Activate.ps1
    pip install --upgrade pip
    pip install -r requirements.txt
    python -m playwright install chromium
    cd frontend && npm install && cd ..

  MAC (Terminal):
    cd ~/Desktop/SR-VORTEX
    python3 -m venv venv
    source venv/bin/activate
    pip install --upgrade pip
    pip install -r requirements.txt
    python -m playwright install chromium
    cd frontend && npm install && cd ..


================================================================================
  PASSO 3  -  CONFIGURAR O ARQUIVO .env
================================================================================

  Este e o passo MAIS IMPORTANTE. Sem isso o bot NAO funciona.

  Dentro da pasta do projeto, abra o arquivo chamado:

      .env

  WINDOWS: Abra com o Bloco de Notas (clique direito > Abrir com > Bloco de Notas).
  MAC: Abra com TextEdit ou VS Code. No Terminal: nano .env

  Se nao aparecer o arquivo, ative "Mostrar arquivos ocultos":
    Windows: Explorador > Ver > Mostrar itens ocultos
    Mac: No Finder, aperte Cmd+Shift+. (ponto)

  Voce precisa preencher OBRIGATORIAMENTE estas linhas:

  -----------------------------------------------------------------------
  CAMPO                   | O QUE COLOCAR
  -----------------------------------------------------------------------
  PANEL_USERNAME          | Um nome de usuario para voce acessar o painel
                          | Exemplo: meuuser
  -----------------------------------------------------------------------
  PANEL_PASSWORD          | Uma senha para acessar o painel
                          | Exemplo: minha_senha_forte
  -----------------------------------------------------------------------
  PANEL_AUTH_SECRET       | Uma chave de seguranca aleatoria.
                          | Abra o PowerShell e digite:
                          |
                          |   python -c "import secrets;print(secrets.token_urlsafe(48))"
                          |
                          | Copie o resultado e cole nessa linha.
  -----------------------------------------------------------------------

  >>> Sem essas 3 o painel NAO abre. <<<

  -----------------------------------------------------------------------
  CAMPOS DAS APIs (preencha os que voce tiver):
  -----------------------------------------------------------------------
  NUMERO_VIRTUAL_API_KEY  | Sua chave da numero-virtual.com (SMS)
                          | Sem ela: SMS fica manual (voce digita o codigo)
  -----------------------------------------------------------------------
  NUMERO_VIRTUAL_CUSTOMER_SESSION
                          | Cookie JWT da numero-virtual.com
                          | Pega no navegador: F12 > Application > Cookies
                          | Copie o valor do cookie "customer_session"
  -----------------------------------------------------------------------
  CAPSOLVER_API_KEY       | Sua chave do capsolver.com (captcha automatico)
                          | Sem ela: captcha fica manual
  -----------------------------------------------------------------------
  INFOSIMPLES_API_TOKEN   | Sua chave da infosimples.com (PDF comprovante)
                          | Sem ela: PDF de comprovante fica desabilitado
  -----------------------------------------------------------------------

  Os demais campos ja vem com valores padrao. NAO mexa neles a menos que
  saiba o que esta fazendo.

  >>> NUNCA use # (cerquilha/hashtag) dentro de valores no .env <<<
  >>> O Python interpreta # como comentario e corta o valor <<<

  Depois de preencher, salve o arquivo (Ctrl+S) e feche.


================================================================================
  PASSO 5  -  CONFIGURAR O ADSPOWER
================================================================================

  1. Abra o AdsPower e faca login na sua conta
  2. O bot se conecta ao AdsPower pela porta local (127.0.0.1:50325)
  3. O AdsPower precisa estar ABERTO durante todo o tempo que o bot rodar

  A chave de API do AdsPower (ADSPOWER_API_KEY no .env) e OPCIONAL.
  O bot funciona sem ela. So preencha se quiser.

  Os perfis de navegador, proxies e contas Facebook serao cadastrados
  pelo painel do bot depois que ele estiver rodando.


================================================================================
  PASSO 6  -  INICIAR O BOT
================================================================================

  Tudo pronto? Agora e so iniciar:

  WINDOWS:
    Duplo clique em: INICIAR_TUDO.bat

  MAC:
    Duplo clique em: INICIAR_TUDO.command
    ou
    Duplo clique em: INICIAR_AUTOMACAO.command (tambem abre AdsPower e Chrome)

  Ele abre DUAS janelas:
    - Backend  = servidor da API   em http://localhost:8000
    - Frontend = painel visual     em http://localhost:5173

  Depois de ~30 segundos o navegador abre automaticamente no painel.
  Faca login com o PANEL_USERNAME e PANEL_PASSWORD que voce definiu.

  -----------------------------------------------------------------------
  SE PREFERIR INICIAR MANUALMENTE:
  -----------------------------------------------------------------------

  Abra DOIS terminais separados.

  WINDOWS — Terminal 1 (backend):
      cd D:\SR-VORTEX
      .\venv\Scripts\Activate.ps1
      python -m uvicorn api_server:app --host 0.0.0.0 --port 8000 --reload

  MAC — Terminal 1 (backend):
      cd ~/Desktop/SR-VORTEX
      source venv/bin/activate
      python -m uvicorn api_server:app --host 0.0.0.0 --port 8000 --reload

  Terminal 2 (frontend — igual nos 2 sistemas):
      cd <pasta>/frontend
      npm run dev

  Abra o navegador em: http://localhost:5173

  -----------------------------------------------------------------------

  Scripts separados:
    Windows: INICIAR_BACKEND.bat / INICIAR_FRONTEND.bat
    Mac:     INICIAR_BACKEND.command / INICIAR_FRONTEND.command

  Para PARAR o bot: feche as duas janelas (ou Ctrl+C em cada uma).


================================================================================
  PASSO 7  -  PRIMEIRAS CONFIGURACOES NO PAINEL
================================================================================

  Quando o painel abrir, voce precisa configurar PELO PAINEL:

  1. ABA "APIs" (/apis)
     - Clique em "Verificar APIs" para testar se suas chaves estao ok
     - Ele mostra saldo e status de cada servico

  2. ABA "Proxies" (/proxies)
     - Cadastre seus proxies (IP:Porta:User:Senha)
     - O bot precisa de proxy para rodar as contas

  3. ABA "Contas" (/contas)
     - Adicione as contas Facebook que o bot vai usar
     - Formato: email:senha (uma por linha)

  4. ABA "CNPJs" (/cnpjs)
     - Adicione os CNPJs que serao usados nas BMs
     - Pode importar lista ou adicionar manualmente

  5. ABA "Configuracoes" > "Dominios"
     - Cadastre seus dominios + token da Cloudflare/Netlify
     - Necessario para a verificacao de dominio das BMs

================================================================================
  PROBLEMAS COMUNS — WINDOWS
================================================================================

  PROBLEMA: "CMD fecha sozinho ao rodar um .bat"
  SOLUCAO:  Abra o CMD manualmente (Win+R > cmd > Enter)
            Navegue ate a pasta: cd /d D:\SR-VORTEX
            Rode o .bat pelo CMD: INSTALAR_DEPENDENCIAS.bat
            Assim voce ve o erro antes de fechar

  PROBLEMA: "python nao e reconhecido como comando"
  SOLUCAO:  O Python nao esta no PATH. Tente:
              py --version
            Se funcionar, use "py" em vez de "python".
            Se nao funcionar, reinstale o Python marcando "Add to PATH".

  PROBLEMA: "Erro de permissao no PowerShell (scripts desabilitados)"
  SOLUCAO:  Rode como Admin:
              Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

  PROBLEMA: "Erro ao iniciar / venv quebrada"
  SOLUCAO:  Apague a pasta venv/ inteira e rode no PowerShell:
              cd D:\SR-VORTEX
              python -m venv venv
              .\venv\Scripts\Activate.ps1
              pip install -r requirements.txt
              python -m playwright install chromium

  PROBLEMA: "Frontend nao abre / erro de node_modules"
  SOLUCAO:  Rode no PowerShell:
              cd D:\SR-VORTEX\frontend
              Remove-Item -Recurse -Force node_modules
              npm install


================================================================================
  PROBLEMAS COMUNS — MAC
================================================================================

  PROBLEMA: "Nao foi possivel abrir porque o desenvolvedor nao pode ser verificado"
  SOLUCAO:  Botao direito no arquivo > Abrir > Abrir
            Isso so acontece na primeira vez.

  PROBLEMA: "Permissao negada" ao rodar um .command
  SOLUCAO:  Abra o Terminal, va ate a pasta do projeto e rode:
              chmod +x *.command

  PROBLEMA: "Python 3 nao encontrado"
  SOLUCAO:  Instale via Homebrew:

  PROBLEMA: "Node nao encontrado"
  SOLUCAO:  brew install node

  PROBLEMA: "venv quebrada (copiada de outro Mac)"
  SOLUCAO:  No Terminal:
              cd ~/Desktop/SR-VORTEX
              rm -rf venv
              python3 -m venv venv
              source venv/bin/activate

              python -m playwright install chromium

  SOLUCAO:  No Terminal:

              rm -rf node_modules package-lock.json
              npm install

  PROBLEMA: "Playwright: browser was not installed"
  SOLUCAO:  venv/bin/python -m playwright install chromium


================================================================================
  PROBLEMAS COMUNS — AMBOS OS SISTEMAS
================================================================================

  PROBLEMA: "Nao consigo acessar o painel"
  SOLUCAO:  Verifique se as 3 variaveis PANEL_* estao preenchidas no .env
            Reinicie o backend

  PROBLEMA: "AdsPower connection error"
  SOLUCAO:  O AdsPower precisa estar ABERTO e LOGADO na maquina
            Verifique se a porta 50325 nao esta bloqueada

  PROBLEMA: "SMS nao chega"
  SOLUCAO:  Verifique o saldo na numero-virtual.com
            Verifique se NUMERO_VIRTUAL_API_KEY esta preenchida
            Verifique se o NUMERO_VIRTUAL_CUSTOMER_SESSION nao expirou
            (expira a cada ~7 dias, precisa renovar)

  PROBLEMA: "Captcha manual toda hora"
  SOLUCAO:  Preencha CAPSOLVER_API_KEY com sua chave do capsolver.com
            Verifique o saldo no capsolver.com

  PROBLEMA: "PDF comprovante nao gera"
  SOLUCAO:  Preencha INFOSIMPLES_API_TOKEN no .env


================================================================================
  RENOVAR O COOKIE SMS (A CADA ~7 DIAS)
================================================================================

  O cookie NUMERO_VIRTUAL_CUSTOMER_SESSION expira a cada ~7 dias.
  Quando expirar, o painel mostra um aviso amarelo.

  Para renovar:
  1. Abra https://app.numero-virtual.com no navegador
  2. Faca login na sua conta
  3. Aperte F12 (ferramentas do desenvolvedor)
  4. Va em Application > Cookies > app.numero-virtual.com
  5. Encontre o cookie "customer_session"
  6. Copie o valor inteiro
  7. Cole no .env na linha NUMERO_VIRTUAL_CUSTOMER_SESSION=
  8. Reinicie o backend

  O painel mostra quantos dias faltam para expirar na aba APIs.
